# Changelog

## 1.2.0 — public experimental release

- Launcher-agnostic One UI Home handoff targeting the selected third-party default Home app.
- Early Home input release while preserving visible closing motion and stock Recents.
- Closing-duration setting; no opening-duration slider.
- Authenticated read-only settings provider, reduced diagnostic metadata and disabled backup/transfer extraction.
- New project-only app identity, release signing identity and original adaptive icon.
- Open module source, security-review limitations and prominent vibecoded / AI-assisted disclosure.

This version remains experimental. It does not claim universal launcher/firmware compatibility or guaranteed security.
